# Change Log

All notable changes to the Quasar UI Tool VS Code extension are documented here.

## 0.1.0

Initial Marketplace-ready release.

- Added visual editor support for Quasar UI page JSON files under `.src/pages/*.json`.
- Added Screen, Script, component palette, page tree, properties, and dataset views.
- Added Vue + Quasar runtime preview inside the custom editor.
- Added JSON to Vue generation workflow support.
- Added Pinia store helper commands.
- Added rule-based tagged PowerPoint to JSON conversion.
- Added Screen JSON to PowerPoint design sheet export with round-trip metadata.
